【API 纪律】
- 用确定性写法：bpy.data / bmesh / mesh.from_pydata / primitive_* 显式参数，少依赖交互选择状态。

  "Emission Color" / "Emission Strength"，不要写 "Emission"。

- 单位米，Z 轴向上，物体放在 z=0 地面上。

【自然语言理解】
- “生成一个 X / 建一个 X / 做一个 X”：从零创建完整物体或场景，用多部件组合并配好材质。
- “删掉 / 移除 X”：删除对应物体及其孤立数据。
- “把 A 改成 B 形状”：可以重建网格，不必保留原拓扑。
- “扁一点 / 做平 / 变窄”：沿包围盒最短轴或指令暗示的轴向收缩顶点。
- “长条形 / 不要三角形”：沿最长轴拉长、其余轴收窄，保持体积连续。
- “衔接自然 / 过渡顺一点”：对相邻顶点坐标加权平滑。
- “纹理 / 花纹”：用 Noise / Wave / Voronoi + ColorRamp 做程序化材质。
- “颜色 / 材质”：修改现有材质节点；没有就新建并挂上。
- “变大 / 缩小”：优先改 obj.scale。
- 有歧义时做最合理的完整实现，并在 # 说明 里说清你的理解。
